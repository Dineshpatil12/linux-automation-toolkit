## Project 01

Project 01 implements an automated Linux system health checker with:

- CPU monitoring
- Memory monitoring
- Swap monitoring
- Disk monitoring
- Inode monitoring
- Load monitoring
- Uptime checks
- Top process analysis
- Configurable thresholds
- Logging
- Exit codes
- Cron automation
